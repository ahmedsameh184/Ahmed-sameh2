# Ahmed Sameh — Computer Engineering Portfolio

This repository contains the portfolio website in `index.html`. The HTML file includes the page markup, CSS, JavaScript, and embedded images (data URLs), so no separate image folder is required for the embedded images.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Upload `index.html` and this `README.md` to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

Review the page before publishing and remove any personal contact details you do not want public.
